# ADR 002：多语言客户端通过公共 API 访问底座

状态：接受，2026-09-10。

Java 和 Python 业务系统需要复用同一知识库。SDK 放在独立 sdk/java 和 sdk/python 包中，只依赖公共 HTTP API，不能依赖 Java 业务类、Worker 内部接口或存储客户端。服务端仍是身份与权限的唯一权威。

两种 SDK 提供一致的知识库创建、上传、任务查询、索引、发布、检索和 SSE 问答能力。Python 提供同步与异步客户端；Java 提供阻塞请求和事件回调。语言无关的接口定义保留在 OpenAPI，契约测试验证路径和重要请求行为。

初版手写客户端以正确管理 multipart、SSE 和错误生命周期；响应使用 dict / JsonNode 保留字段扩展能力，请求 Query 与事件有明确类型。代价是两个实现需要同步维护；CI 分别运行测试。后续响应 DTO 和代码生成必须保持相同的鉴权、完成和异常语义。

客户端不自动重试 HTTP 错误、不跟随重定向；调用方可以显式提供请求键。SSE 必须收到 done 才算完成，服务器 error 和提前 EOF 均失败。退出上下文或回调异常关闭响应连接。SDK 不改变服务端计费和授权规则。

SDK 当前只在本地构建安装，未发布公共包仓库。许可、发布元数据和真实全链路联调仍属于正式发布前事项。
