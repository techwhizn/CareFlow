# ADR 003：模型连接注册与密钥边界

状态：接受，2026-09-10。对应V1-01。

模型连接由Java管理，按企业隔离，仅OWNER/ADMIN可创建、读取和修改。控制器只做校验映射，服务处理策略、事务与审计，Repository负责SQL，Vault负责密钥封装。

API Key采用AES-256-GCM随机nonce加密，AAD绑定tenant与profile ID；主密钥来自部署环境，不写入数据库。响应只返回key_configured，永不回显密钥或密文；更新null保留，空串清除，非空替换。更换地址或类型不能静默沿用旧密钥。revision用于乐观锁。

目标地址只能从部署管理员给定的精确base URL白名单选择，外部和自托管地址分别配置，UI不能任意添加地址。地址禁止用户信息、查询串、片段及任意路径（仅根或/v1）。外发声明必须匹配白名单类别；模型调用阶段仍须在发送前检查企业与应用策略，V1-02/03接入时不得跳过。连接注册本身不发网络请求，故不能用保存成功宣称供应商可用。

外部批准地址的DNS与网络出口由部署管理员控制；后续连接检测需处理重定向、DNS/内网访问防护，不能仅凭UI白名单宣称完整网络安全。自托管地址只有部署管理员明确批准后可用。

V4新增表，不修改旧迁移。配置绑定与版本快照属V1-03，此阶段现有Worker环境配置继续工作。已存配置暂不参与检索；UI和文档明确该边界。
