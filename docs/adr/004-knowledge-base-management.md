# ADR 004：知识库属性、责任人和统计归属

状态：采纳，2026-09-10。

知识库公共控制器只映射请求；KnowledgeBaseService执行授权、事务与责任人规则，KnowledgeBaseRepository集中本功能SQL。保留原列表、创建及读取路径，新增属性修订、设置快照和概览。状态生命周期单独处理。

责任人是具备知识管理角色的启用成员，移交改变隐式资源权限，已有显式ACL不自动删除。修订号与ACL共用，防止属性修改覆盖并发授权；修改成功只返回确认，避免移交后因原责任人失去读取权限导致整个事务回滚。

统计对文档和版本分别授权。空间表示授权可见原文件对象占用，按对象键去重，历史缺少大小记录显式报告未知；不是整个租户账务空间。V8增加可空size_bytes，不为历史数据伪造大小。只记录对象元数据，禁止在统计请求中从对象存储下载文件正文。

应用关系沿用现有应用管理角色边界；无权限时不披露应用名。模型、任务和存储计量仍分别属于后续工作包。
