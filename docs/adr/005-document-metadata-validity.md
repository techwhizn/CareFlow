# ADR 005：文档元数据与即时有效期

状态：采纳，2026-09-10。

标题、来源、语言、标签、型号和业务有效期属于Java文档元数据。更新按文档revision原子保存并记录前后快照；服务层负责规则，Repository负责SQL。此更新不修改已发布知识正文；可作为撤回失效材料的即时控制。

接口要求明确时区，UTC归一化后存DATETIME，避免TIMESTAMP的2038年范围限制。读取兼容JDBC返回的LocalDateTime与Timestamp，在UTC语义下转换，不能依赖主机默认时区。查询参数也使用UTC LocalDateTime。文档有效期与已有版本有效期取交集；召回、外发/交付、历史答案的证据复核均遵守文档当前有效期。

来源仅为描述字段，不引入URL抓取；元数据历史含业务属性，需文档编辑权限查看。类型化召回过滤在V1-25单独实现，当前仅有效期参与默认范围过滤。
