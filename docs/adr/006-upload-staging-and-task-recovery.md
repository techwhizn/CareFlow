# ADR 006：上传短事务、暂存补偿与任务检查点

状态：采纳，2026-09-10。

上传不得在持有企业锁和数据库事务时等待S3。先登记唯一暂存键并提交；事务外存文件；最后重新认证、授权和核对幂等，再原子挂接版本/任务/Outbox。并发同请求允许产生短暂冗余对象，但只能产生一份有效任务，未挂接对象由定时补偿清理。正常结束前的对象不可通过公共文档API读取。

暂存挂接与清理用状态条件更新互斥。清理不复用键，挂接对象有版本引用时不删除；存储删除失败保留租约重试。15分钟暂存有效期大于S3请求时间上限。旧存量孤立文件不在本迁移自动删除范围。

任务处理沿用Java拥有的租约与最多3次尝试。补充可见阶段检查点与心跳，旧回调不能修改取消或已删除数据。恢复、取消和完成遵循企业再任务的锁顺序。检查点不是跨进程内存快照：只恢复任务安全起点，不声称模型供应商成本可以回滚。
