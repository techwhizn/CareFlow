# ADR 007：按业务拆分Java控制器

状态：采纳，2026-09-10。

移除ManagementController和DocumentsController。应用及配置、初始化、个人凭证/审计、用量、文档查询、草稿/索引、文档发布/删除、任务查询分别进入对应Service；控制器仅负责HTTP映射、Bean Validation、转发和下载响应头。事务标注放到执行规则的服务方法，保留现有锁顺序、冲突检查和回滚语义。

SQL保留在所属业务服务或已存在的专用Repository中，Db只是底层执行工具；不建立跨业务通用管理服务。上传协调继续由DocumentUploadService拥有，不重新引入控制器事务。下载用SourceFile记录跨服务边界，二进制正文和文件名到控制器后再映射HTTP响应。

此步保留现有REST路径/请求字段和业务行为，以既有授权、发布冲突、草稿隔离及存储失败回归验证。未把所有Map一次性替换为领域实体；检索/Worker协议和问答历史仍有通用结构，V1-48及后续对应业务任务继续收敛。
