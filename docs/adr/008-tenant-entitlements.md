# ADR 008：由 Java 在租户事务内执行资源限制

状态：采纳。

成员、知识库、上传预占、查询预占与任务领取共同竞争企业资源。额度检查放在 Java 服务层，并与现有租户行锁和资源写入使用同一事务，避免控制器检查后并发越限。上传 S3 I/O 仍在数据库事务外，使用暂存空间预占和最终二次检查。

套餐调整采用修订号与审计，不改变历史用量。首版处理额度明确采用首次领取任务次数；实际模型用量是独立计量维度，后续不得暗中替换单位。PDF 限制通过内部 v1 任务契约传入 Python 子进程，只允许收紧部署上限。

代价是同租户写入串行、存储计数需要扫描对象元数据；数据规模扩大时可改为带核对机制的物化计数。累计额度不自动按月刷新，周期结算需要独立设计。套餐暂停保留管理和数据读取，运行中的任务允许完成。
