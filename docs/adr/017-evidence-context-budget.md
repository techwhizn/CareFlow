# ADR 017：授权上下文与证据Token预算

状态：已采纳。日期：2026-09-10。

Rerank后的证据整理归Java业务层，Worker仅提供固定cl100k_base计数。EvidenceContextService只从同版本权威内容构建候选扩展；发送文本计数前重新认证，返回证据和生成前重新校验资源及全部覆盖切片启用状态。被禁用的子片段阻断完整父内容扩展。

EvidenceSelection负责分数门槛、确定重复、同文档条数和6000证据Token上限。重叠扩展可以退回未覆盖命中本身，避免既重复发送又丢弃新的相关命中。精确来源重叠与完全重复文本可去重，不依赖模型推测两个资料是否等价。

响应保留命中内容和扩展来源，让SDK、调试台与后续引用校验使用同一事实。Token预算和供应商计费分离；完整模型输入仍受模型原生窗口约束。参见 [证据整理契约](../evidence-context.md)。
