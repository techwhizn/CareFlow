# ADR 018：会话范围、上下文与传递授权依赖

状态：接受，2026-09-10。

多轮问答可能把已撤权资料通过历史答案再次发送给模型。会话因此绑定租户、主体类型、主体、应用及显式知识范围，不能跨范围复用。Java 是授权与历史的所有者，Worker 只接收经过检查且受 Token 上限约束的历史。

最近六轮、3000 Token 的限制由固定 tokenizer 计算，Java 选择上下文，Worker 生成入口再次校验总量。会话使用有期限的在途请求与事务内修订号，禁止并行答案混排。

答案保存本次引用快照，同时保留上下文的传递切片依赖。授权检查和物理清理遍历所有依赖，避免答案间接保留已删除资料。当前引用与历史依赖通过 `evidence_role` 区分，只有当前引用出现在引用面板。

代价是每轮输出需要更多授权查询，历史依赖可能随对话增长。后续性能优化必须保持等价的撤权边界，不能用无限期缓存跳过权限检查。V25 为新增迁移，兼容旧单轮答案及旧客户端；旧记录没有快照时读取当前仍有权访问的切片。
