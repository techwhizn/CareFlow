# ADR 019：应用查询策略与知识索引身份分离

状态：接受，2026-09-10。

同一知识库需要服务不同问答应用。将应用的 Rerank/生成模型、检索默认值及回答约束保存为应用配置版本，并通过发布指针和修订历史切换。负责人是责任信息，不是隐式授权。

查询 Embedding 始终跟随文档版本索引时的模型身份。应用模型只作用于召回后的统一重排与生成；因此可以查询配置不同的多个知识库，而不破坏索引维度和模型身份隔离。没有显式应用模型时保持已有知识库兼容性检查。

ModelSnapshotService 供知识配置与应用配置共享不可变模型快照，公开配置仅含档案引用和修订。发布/回滚检查当前绑定授权及部署地址许可；保存后更新档案不会暗改旧版本。

回答约束限定为语言、风格、输出及历史预算，避免开放替换系统提示的入口。任何配置都不能授予资料权限或允许工具执行。
