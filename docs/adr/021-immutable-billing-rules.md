# ADR 021：冻结执行费率，保留未知成本

状态：接受。

查询和处理用量已经持久化，但使用当前价格显示历史费用会造成旧结果随配置改变，缺失模型用量也容易被误读为免费。

由 Java 管理不可变费率版本，企业激活指针使用 revision 并发控制。新任务及查询在原有租户事务锁内绑定当时的费率；费用读取根据冻结费率与实际用量计算，允许迟到用量补齐而不改变单价。客户费用与内部资源成本分别返回，后者仅限管理员。缺失价格或用量返回部分金额及未知状态，不生成虚假总金额。

导入预估调用现有 Tokenizer 契约，不执行付费处理阶段。客户端可提交预估看到的费率 revision，上传服务在写入前与最终挂接事务中校验；并发价格变化时拒绝提交并清理暂存对象。源文件写入量按新对象计算，重复处理不重复计入。

代价：管理员需要自行维护单价；预估无法覆盖解析前未知的 OCR 文本或结构变化；实际金额可能随迟到用量补齐。系统不承担支付、供应商账单核对或税务发票职责。
