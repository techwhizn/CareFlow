# ADR 022：关联执行与独立调试保留策略

状态：接受。

HTTP 请求、异步任务和流式查询具有不同生命周期。以 Java 生成的 HTTP ID 作为入口关联，以 job_id/查询执行 ID 作为异步阶段关联，存储映射并显式向 Worker 传递。线程上下文使用词法作用域清理，异步线程显式建立上下文，不依赖继承线程本地状态。服务身份认证后才信任内部关联 ID；关联 ID 不参与授权。

运行指标从租户账本聚合，避免内存重启丢失、跨企业聚合或正文标签泄露。提供受权限保护的 JSON/Prometheus 端点与页面告警。健康探测只检查声明的进程/数据库范围，不隐式调用付费模型。

调试问题副本可以关闭或按保留期清除，执行元数据和证据依赖保留。会话和问答历史是用户产品数据，保留与删除由各自生命周期控制。清理按租户锁、有限批次和幂等更新实施，避免长期占用业务事务。配置变更保留审计，审计自身按到期策略删除。

V34 已应用后发现审计索引与 V1 重复，以 V35 删除冗余索引，保留迁移历史不变。
