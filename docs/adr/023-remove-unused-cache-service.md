# ADR 023：默认部署移除未使用的缓存服务

状态：接受，2026-09-11。补充ADR001的Redis预留方案。

当前应用限流、并发准入、配额和任务公平调度均由Java服务及MySQL事务实现，Java/Python没有Redis客户端或缓存读写。默认Compose继续启动Redis只增加进程、端口与维护范围，不提供已实现能力。因此移除预留服务和启动命令；需要缓存时按实际场景另立决策，说明一致性、失效和恢复语义。

这是对PRD初始技术选型中缓存项的实现收敛，不改变限流和配额验收要求。独立安装验证使用无Redis环境执行。

已有部署的数据卷不会被该变更删除。旧Redis容器可以在确认没有仓库外使用者后停止；不要使用全局容器或卷清理命令。没有CareFlow缓存数据迁移步骤，因为项目从未写入该服务。
