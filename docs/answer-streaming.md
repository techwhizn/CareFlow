# 流式问答与取消

公共`POST /api/v1/answers`以SSE返回start、status、delta、usage、citations、done或error事件；注释心跳不是业务事件。Java负责授权、检索、交付与计量，Python负责真实模型HTTP适配。只有收到done，客户端才把回答标记完成；流提前结束、错误或用户停止都保留“未完成”状态。

AnswerStreamService拥有问答生命周期；SseEmitter断连/超时回调取消执行线程并关闭当前内部HTTP输入流。每2秒注释心跳帮助发现等待期间的下游断开；这是检测频率，不是所有网络环境中的绝对取消时限。生成前、每段文字和用量交付前复核身份及证据权限。Python使用异步HTTP读取，ASGI取消能关闭正在等待的模型连接，不必等到下一段文字或90秒读超时。

模型仍可能在网络取消到达前发生消耗，断开连接不代表供应商已免计费。generation_usage按查询request_id独立记录供应商报告的input/output/total_tokens，以及请求完成和用量状态；不保存问题、答案或密钥。已报告计数在取消/失败后保留，缺失字段保持NULL。STARTED而未收到报告的中断标记UNKNOWN；成功但供应商未返回用量标记NOT_REPORTED；无证据未调用生成为NOT_CALLED。计数来自供应商，不用字符数或逻辑Token代替。

usage事件只含计数；未报告字段为null或缺省，客户端显示未知。它不是done，也不是回答文本。完成答案才写入历史；开始生成后被取消的未完成回答不作为历史答案保存。流传输无法保证最终事件被客户端确认接收，历史保存与网络接收之间的结算细节继续按V1-38完善。

前端增量解析UTF-8与跨分包CRLF，忽略心跳，限制单事件大小，done/error后立即关闭读取器。两种SDK允许额外usage事件并在未收到done时报告失败；Python离开answer上下文、Java回调抛出异常可关闭流。

## 升级

V24新增generation_usage及请求关联索引，不改变既有答案。先升级Java协议与数据库，再升级Worker；新Java接受旧Worker未提供usage的流，用量不能追补成0。升级前排空活跃问答；正在执行的旧进程不会自动具备取消能力。迁移回退先停止新写入、导出generation_usage，旧版本可保留新增表运行；不应删除真实用量记录。进程崩溃遗留请求的统一恢复由V1-38补齐。
