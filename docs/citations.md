# 引用校验、冲突说明与原文定位

## 流式引用协议

生成模型必须使用 `[完整证据ID]`，且该 ID 必须属于本次 Java 授权、筛选后的证据集。方括号专用于引用，不使用数字脚注或 Markdown 链接。Java 将跨 delta 的括号内容缓冲到闭合，验证后才交付；未知、嵌套、超长、残缺或完全缺失引用返回 `INVALID_CITATION`，不保存成功答案、不递增会话轮次。已输出的普通文字显示为“未完成”。无证据时由服务直接拒答，不要求模型虚构引用。

这个校验保证引用身份合法，不能证明每个事实都被引用支持；语义正确性、冲突识别质量仍需要评估集及人工评审。模型不会获得下载权限或执行权限。

## 来源与适用时间

本次证据包含文档 ID、版本 ID、切片 ID/修订号、原文位置、覆盖切片和文档/版本适用时间。生成请求携带受控的标题、身份和适用时间元数据。提示要求对相互矛盾资料分别引用、解释适用时间，不擅自指定唯一结论。页面展示双方来源和时间，不把“文件较新”自动等同于“业务规则优先”。

成功回答保存引用内容及所有覆盖切片的原始提取内容、位置和修订快照。原文编辑不会改变已有快照；删除或撤权仍会隐藏快照。旧答案没有原文快照时明确标注只可核对当前同版本来源。

## 查看与下载

点击正文引用可展开对应证据；点击“定位引用原文”调用：

`GET /api/v1/answers/{answer}/citations/{citation}`

服务重新校验答案的全部当前和历史依赖，仅允许打开该答案的当前引用。返回 `source_snapshot`、`source_chunks` 和定位字段。文本显示来源区间，PDF 显示页码，表格显示工作表/行/单元格范围，人工内容明确标注没有原文件精确定位。当前方案展示保存的提取原文，不声称 PDF 页面像素区域精确高亮。

下载继续调用 `/document-versions/{version}/source`，单独验证 `download` 权限。拥有问答或原文提取内容的读取权限不意味着可以下载整个文件。

SDK：Python `citation_source(answer_id, citation_id)`（同步/异步）；Java `citationSource(answerId, citationId)`。
