# 套餐与资源限制

企业所有者与管理员通过管理后台“套餐与用量”或 `GET/PUT /api/v1/entitlement` 人工开通、续期、停用和调整限制。无需在线支付。写入必须携带当前 `revision` 与非空 `reason`；并发修改返回 409，调整前后配置、操作者与原因进入审计。旧 `/quota` 仅调整累计查询上限，同时推进套餐修订号。

## 资源口径

| 资源 | 计数与限制 |
| --- | --- |
| 成员 | 启用且未移除成员，包括所有者；禁用释放名额，恢复重新检查 |
| 知识库 | 未删除知识库，包括归档；恢复不新增名额 |
| 文件空间 | 不同源文件对象去重计数，包含历史版本与待清理对象；上传期间预占实际字节；旧版本缺少大小时每个按 50 MiB 保守预留并显示未知对象数 |
| 处理额度 | 累计首次领取的 PARSE / INDEX 任务次数；内部自动重试不再计数，首次领取后失败、取消仍占一次；另建任务重新计数 |
| 查询额度 | 沿用成功结算计数与执行中预占；失败释放预占 |
| 查询并发 | 当前查询预占数；租户锁内检查并预占 |
| 处理并发 | RUNNING 任务数；租户锁内检查并发、处理额度和领取 |
| PDF 页数 | 默认 500，可收紧到 1；Worker 子进程使用部署限制与租户限制中较小者，在解析早期拒绝超页 |

计数目前是累计口径。人工续期仅更改有效期和上限，不自动重置用量；不存在自动周期刷新。OCR 页数、模型 Token 和实际调用计量另见 V1-37，不能将处理任务次数解释为 Token 用量。

空间额度不会因逻辑删除立即释放：物理清理由 V1-23 补齐。V10 上传暂存清理成功后可释放对应暂存空间。上传在上传前与最终入库前均检查，管理员中途收紧或停用会阻止入库，暂存对象随后清理。

## 有效期与超限行为

时间使用带时区 ISO 8601 输入，按 UTC 保存。开始时间包含该时刻，到期时间不包含；留空分别表示立即生效、无到期时间。停用、未开始或到期返回 `403 ENTITLEMENT_INACTIVE`，阻止新增成员、恢复成员、新建知识库、上传、查询和新任务领取。已运行任务允许完成；已有文件读取、管理、删除、审计仍可访问，权限检查继续生效。

超限返回 `429 QUOTA_EXCEEDED`，不会自动删除已有资源；降低额度至当前用量以下允许保存，之后新增请求被拒绝。任务仍保持 QUEUED、不增加尝试次数，由现有队列重投；恢复可用额度后可以领取。当前队列尚无跨租户公平调度，见 V1-44。

预警为管理页面与 GET 响应中的资源阈值标记，默认 80%；没有邮件通知或定时推送。查询预警包含预占，空间预警包含暂存。

## 迁移与恢复

V12 为现有企业补默认限制：100 成员、100 知识库、10 GiB 空间、10000 处理任务、10 查询并发、2 处理并发、500 PDF 页，默认启用且无有效期边界。保留现有查询上限与累计用量；历史已领取任务不补扣处理次数。旧暂存记录按 50 MiB 保守预留。

升级前备份数据库并核对实际资源与默认限制；已有资源超过默认值不会删除，但应由管理员调整限制。回退应用时保留新增列；禁止删除已应用迁移或清空计数以回退。旧 Worker 不支持租户 PDF 限制，应停止消费者，完成 Java 与 Python 同步升级后再恢复处理。
