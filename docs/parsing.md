# 文件解析与来源契约

Java管理文件、任务和授权；Python只解析字节与文件名并返回切片。所有解析产物先作为草稿，不自动发布。

| 格式 | 提取方式与定位 | 限制和警告 |
| --- | --- | --- |
| TXT | UTF-8（允许BOM）；原始解码字符start/end | 空白清洗保留source_text；拒绝NUL/无效编码 |
| Markdown | 标题分节、title_path及准确字符偏移，保留列表/表格/代码原文 | fenced代码块中的标题不分节；表格保留源行并提示核对 |
| DOCX | 按正文顺序遍历段落/表格；标题路径、列表标识、段落序号、表格序号和行列 | 合并/嵌套表格、空/重复表头明确警告；不读取执行宏、嵌入对象 |
| CSV | 第一行为表头；每行保留字段名和值、行号和列范围 | 表头列数不匹配不丢数据，标记警告 |
| XLSX | 工作表、行号、列范围和cell_range；空单元格不改变坐标 | 行展开不推测合并含义；公式保留表达式并警告未计算，不执行或外链刷新 |
| PDF | layout提取基础文本布局，逐页记录page；低文本页进入OCR | 阅读顺序与复杂表格需人工核对，不能把纯文本展开宣称为精确还原 |

切片source_text是对应源块范围，content是清洗后检索文本。块内block_start/block_end始终针对清洗前文本；表格源块是带表头的行表示，不冒充Office文件字节偏移。清洗归一化空白/换行，保留对照；不会任意拼接列表或表格行。

PDF至少3页且至少60%的页面出现完全相同的短首/尾行时，标记重复页边文字并从检索文本清除。原文字和ignored_spans保留，可人工核对。少于3页不自动判断。此保守启发式不能识别所有页眉/页脚，存在重复正文误判可能，发布前必须核对警告。

扫描件和图片OCR的真实运行及资源边界另见V1-13；本文不把结构文本测试当OCR验收。
