# 性能报告状态

状态：项目所有者决定不再追求高并发或高性能，本机以功能正常为目标。历史性能基准仅用于说明单机容量边界，不作为1.0功能门禁或生产SLA。

已经验证本机开发依赖能够启动及小型合成资料可真实导入。没有将单个健康检查或小文件处理时间解释为生产性能。

历史测量条件：10万有效切片、至少10个测试租户、5 QPS起步、10并发、明确硬件与供应商部署位置、冷热缓存、网络情况和失败率。曾分别记录普通API、纯检索、Embedding+Rerank全检索、问答首Token的P50/P95。

当前已配置真实BGE Embedding/Rerank与DeepSeek生成，完成60份合成资料、120题候选集的两组检索实验；十万切片/十租户历史基准见[V1-45报告](v1-45-performance.md)。候选集人工评审尚待完成。`worker/careflow/evaluation.py` 可对已标注资料请求真实API并输出延迟和失败率，不要求继续进行本机压力测试。

PRD 起始目标作为可选容量参考保留；当前版本不以这些数字宣称达标，也不要求本机继续测试。
