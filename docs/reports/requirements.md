## 主要独立缺口

- 企业：已补部署管理员多企业开通及成员状态/角色管理；所有权转移未提供，完整授权矩阵与套餐运营仍待验收。
- 知识库：模型/解析/检索配置版本、标签、责任人变更和应用引用概览未完整实现。ACL UI已支持多主体编辑、授权快照及冲突处理。
- 文档与切片：无完整元数据编辑与有效期表单、父子/FAQ 策略、拆分合并、人工修订冲突处理；Markdown 支持结构标题路径，Office 基础解析仍需复杂布局评估。
- 检索与问答：类型化过滤、持久化检索策略、父/相邻扩展、多轮会话和完整引用定位未完成。真实模型输出、引用正确性、拒答率仍待评估。
- 应用：配置草稿/发布/回滚已实现；模型和检索策略仍以环境配置和代码默认值为主。
- 评估：提供真实 API 驱动的确定性指标 CLI；没有完整评估中心、120题经人工标注的数据集、自动改进任务。最终证据上限6，当前 CLI 报 Hit@6，不能据此宣称 Hit@10 达标。
- 商用：只对查询次数原子预占/结算；OCR/Embedding/Rerank/生成/存储分项账务、成本估算、规则版本、套餐周期和并发公平调度未完成。
- 运维：物理删除、备份日志重放、资源公平性、生产限流、监控告警与恢复演练未闭环。查询预占进程中断后的核对释放仍需补全。
