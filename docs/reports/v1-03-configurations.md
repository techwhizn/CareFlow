# V1-03 配置版本验收

日期：2026-09-10。范围：知识库配置版本、任务快照、历史索引路由及Java/Python客户端。仅本地开发验收，没有执行项目发布。

## 已验证

- MySQL从V14实际迁移到V15；配置草稿冻结三个模型档案的观察修订及加密凭证。发布使用独立CAS修订，回滚保留历史。
- 真实上传、解析和索引：接受时绑定A，随后发布B，原版本仍使用A；查询采用B的默认混合检索策略。回滚A后默认恢复关键词召回，过期发布修订返回409。
- 原文件重处理创建新草稿，旧发布指针不变。真实BGE Embedding、Milvus、BGE Rerank和DeepSeek `deepseek-v4-flash` SSE完成，公共响应不含凭证。
- 历史未绑定索引在模型身份完全匹配后显式绑定，并继续真实查询。两个本地端点身份分别建立真实索引、按原身份召回后进行排名融合。两者使用相同固定BGE权重；此项不声称比较两种不同训练模型。
- 浏览器使用合成企业账户验证：配置列表、当前/历史发布、另存草稿、模型修订与外部处理提示、影响确认、原因输入、发布后修订从3变4。保存草稿时原发布仍为A。
- 后端91项测试通过（包括配置12项和模型组排名融合2项），Java SDK7项、Python SDK20项通过；Worker62项通过、1项外部集成默认跳过，真实Milvus证据由本报告专项链路补充。Spotless、Ruff静态与格式、前端TypeScript和生产构建通过。

原始脱敏记录：[配置完整链路](v1-03-configurations-real.json)、[历史索引与分组路由](v1-03-index-routing-real.json)、[先前模型请求上下文验证](v1-03-model-context-real.json)。后端单元测试使用H2和测试替身，未将其计为上述真实依赖证据。

## 边界与后续工作

本项完成配置版本范围。不同知识库的重排、生成或检索策略不一致时明确返回409，应用层统一查询策略属于V1-33。V1-16继续完善结构切片和供应商输入窗口；V1-21/22继续完善增量与重建。本项不代表这些工作或整体1.0完成。

密钥快照不会随档案更新，撤销旧供应商密钥会使依赖它的旧配置失败。配置列表目前展示最新100个版本。完整升级、兼容绑定和恢复约束见[配置文档](../knowledge-configurations.md)和[ADR011](../adr/011-immutable-knowledge-configurations.md)。

提交前检查：控制器只做协议映射；授权、CAS与任务绑定由Java服务负责；Python无业务权限判断；运行凭证不返回浏览器；迁移新增版本；接口、UI、两种SDK和文档同步。没有远端推送、Release或公开制品上传。
