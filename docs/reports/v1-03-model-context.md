# V1-03 配置隔离开发记录

日期：2026-09-10。已完成内部模型配置的请求级隔离，以及旧索引身份校验；本工作包仍为开发中。

发现并修复的行为：原实现直接使用全局Embedding身份选择集合。若部署模型变化且新集合存在，旧版本可能被当作空检索成功。Java现在从授权的发布版本取得原模型身份；缺失或混合身份明确503。Worker复核本次模型与索引身份，不允许悄悄切换集合。

内部请求可携带不可变、带脱敏SecretStr的配置对象；适配器和Milvus维度共同读取该上下文。ContextVar保持并发请求隔离，并在成功、异常和流推进后复原。生成器不跨线程池yield保留ContextVar令牌。原身份散列算法保持兼容，密钥轮换不改变集合身份。

Java77项通过，新增原身份透传与缺失身份阻止模型调用回归；Python60项通过/1项显式跳过，新增9项覆盖旧散列固定值、双线程不同模型/密钥、异常恢复、嵌套上下文、非法URL、身份不匹配和真实Starlette流线程池推进。Ruff/格式检查通过，内部OpenAPI同步。

真实测试启动隔离Worker，将其部署Embedding revision改成合成的新版本：不带原配置的旧索引请求503；带原配置的请求成功读取实际512维BGE/Milvus dense与BM25，无降级。主服务升级后公共Java混合检索、真实重排仍成功。[机器报告](v1-03-model-context-real.json)。首轮测试因本机代理连接被重置失败，限定loopback测试客户端不使用环境代理后重跑通过；未更改生产代理规则。

尚未实现：知识库配置版本的保存/发布/回滚界面、模型档案绑定、持久化任务快照、多个模型身份的自动分组查询、解析/切片配置版本化。不能把内部支持快照调用表述为V1-03整体验收完成。
