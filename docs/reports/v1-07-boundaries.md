# V1-07 全入口授权与外发边界

2026-09-10，完成当前接口范围的权限矩阵、运维角色和外发前复核；后续新增会话/引用接口仍须追加回归。

## 实现与修复

OPS成员只能访问自身身份与本企业运行汇总，HTTP白名单和领域知识访问双重约束，误配read授权甚至责任人身份也不能读取资料。运行页面仅展示任务、清理、生成状态计数。Java与同步/异步Python SDK提供同一公共接口。

修复应用直接读取知识的绑定缺口：所有知识访问同时要求当前已发布绑定与授权，未绑定知识库不能通过切片/父片段/原文直接读取。每组Embedding请求前重新认证及核对版本；生成中撤权后禁止后续文字、持久化答案。授权失败完成错误流时不再误标为用户取消。

## 真实验证

[结果](v1-07-boundaries-real.json)使用两个已有合成企业、新建OPS/USER和测试应用。OPS即使获read授权，16个内容/管理/检索入口仍404；汇总响应无文档、问题、资源ID和密钥。跨企业读取知识库、切片、父片段、原文、任务均404；USER可读切片和任务，但read权限不能下载原文件。

应用可读取绑定知识库，而已授权但未绑定的另一知识库及其直接切片、父片段、原文件不可见；debug=true也不暴露管理调试。使用Python SDK完成真实检索及DeepSeek问答后撤销该用户read，历史整条答案隐藏，切片404，检索范围为空。Java SDK真实读取运行汇总成功，知识列表404。

浏览器以所有者身份检查同一运行汇总页面；OPS导航由角色约束，服务端矩阵使用真实OPS凭证。没有在报告中保存测试凭证。
