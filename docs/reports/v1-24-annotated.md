# V1-24 三种检索与标注证据验收

日期：2026-09-10。真实MySQL、Milvus 2.6.1、BGE Embedding与Rerank。使用 [合成语料及预标注目标](../../examples/retrieval/annotated.json)，每份资料上传、解析、索引、标记型号、发布后经公共Java API查询。

12个案例全部首位命中目标文档：CF-100/E404、CF-200/E207分别通过语义/关键词/混合三种模式；“连不上网”“还原成刚买来时的设置”“凭发票免费维修”等三类同义问题分别通过语义/混合模式。每例记录dense、BM25、RRF融合及真实模型Rerank候选与分数，未发生降级。详见 [机器记录](v1-24-annotated-real.json)。

同一组真实索引验证型号过滤：CF-100仅有两个已发布授权版本进入召回；未知型号范围为空、各路候选为空。V1-25已有类型、注入与权限边界回归，加上本次真实链路，关闭其V1-24前置依赖。V1-21增量索引此前已验收。

复验：通过进程环境设置CAREFLOW_TOKEN，运行 `uv run --project worker python scripts/verify-retrieval.py --source-kb <含真实已发布模型配置的知识库ID>`。脚本新建带“验收”标记的合成知识库，可能产生模型费用，不修改源知识库。输出只包含合成案例、ID、排名与分数，不保存凭证。

这是按源资料预先写定预期的功能验收，不能替代120题人工标注测试集、相关性阈值校准或规模性能验收；这些仍由V1-27、V1-40和V1-45完成。
