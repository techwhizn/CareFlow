# V1-30 多轮会话专项验收

日期：2026-09-10。仅本地开发验收，不代表完整 1.0 发布验收。

## 实现与边界

新增会话服务、请求租约、历史服务和 V25 迁移。会话固定主体、应用和知识范围；上下文最多最近 6 轮、3000 cl100k Token；当前问题含型号时不会被历史型号覆盖。当前证据保存快照，历史传递依赖参与撤权检查与清理。页面、Java SDK、Python 同步/异步 SDK 可继续会话和重新打开带引用的历史。

## 实际执行

- Java 后端 142 项通过，包括 5 项新增会话测试：归属/范围/并发租约、6 轮窗口和 3000 Token、伪造计数 ID、依赖传播与禁用后隐藏、显式新型号保护。
- Worker 121 项通过、1 项 Milvus 可选测试跳过。新增真实 tokenizer 限额和生成消息顺序测试。
- Python SDK 28 项通过，Java SDK 14 项通过；Web 11 项通过且生产构建成功。OpenAPI 由新服务导出。
- 本地真实 MySQL 已应用 V25。真实 DeepSeek 两轮均 `done`，第二轮带入第一轮 177 Token。实际输入/输出分别 1111/322、1288/294 Token；这是供应商返回用量，不是上下文预算估算。
- 同租户其他用户、其他租户和应用主体读取会话均 404；切换知识集合 409。取消第三轮后修订仍为 2、历史仍为 2 条；撤权后两轮历史为空，逐条答案及引用读取均 404。
- 浏览器实际完成两轮，显示第二轮带入 1 轮、202/3000 Token；实际生成明确说明资料没有解释原因。执行新建会话、重新打开历史和引用展示检查。

结构化联调证据见 [JSON](v1-30-conversations-real.json)。资料与用户都是本地合成验收数据。第一次脚本省略必填有效 limit，得到 400；补齐请求后重新执行并通过，不将该脚本错误当产品缺陷。

## 限制

仅验证本地浏览器，跨浏览器完整兼容性仍由 V1-49 负责。会话租约能阻止过期请求提交，但崩溃后的计量预留恢复属于 V1-38。生成引用合法性与原文跳转属于 V1-31；本项不把当前提示词约束表述为强校验。
