# 模型配置页窄屏与加载状态修复

2026-09-11在实际恢复环境逐页检查12个管理页面，390px宽度下模型配置页达到404px并横向溢出，其余11页均为390px。原因是fieldset的默认最小内容宽度及横向标签/长服务地址共同撑宽表单。

模型表单允许收缩，桌面字段换行，窄屏标签和控件纵向排列。加载档案时显示加载态，读取失败时显示错误而不误报空列表；服务地址策略加载期间表单不可提交。页面提示同步改为已实现的配置绑定/发布流程。

真实Chrome组件回归验证长地址、390px布局、受控等待中的加载态、成功后的空态、503错误态不显示空态。测试使用生产组件和明确的合成API响应，不冒充真实后端故障。15个现有Web测试、TypeScript生产构建和生产依赖审计通过。真实业务页面的最终复查另记。
