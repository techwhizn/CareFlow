# CareFlow 1.0 开源首版剩余任务清单

更新时间：2026-09-10。质量目标：**原 PRD 全部 P0 + 已承诺的 Java/Python SDK + 开源交付要求**。本清单不是完成声明，也不是工期承诺。

当前授权是达到开源发布质量：继续本地开发、测试、文档和逐项本地提交。不执行推送、Release、公开包/镜像发布或对外部署；涉及远端配置的工作先产出可审查的配置和操作手册，实际启用另行授权。

## 范围与现状

- 已有基础：真实导入与切片编辑、版本/权限组件测试、BM25真实组件验证、DeepSeek Flash流式调用、请求级相关性门槛、Java/Python SDK及基础CI。已有能力继续复用，下面列的是补全、重构或验收工作。
- 已有真实Embedding/Rerank、Milvus混合检索及DeepSeek完整问答链路证据，见[V1-02](../reports/v1-02-models.md)。Apache-2.0已确定，维护渠道和远端配置准备待落实。历史需求表有部分滞后，以代码与最新专项验收报告核对后更新，不能把旧“未完成”直接理解为没有任何代码。
- 不纳入首版：Agent、业务意图实现、工具执行、工作流、SSO、自定义角色、企业连接器、知识图谱、插件市场、在线支付和自动续费。轻量知识问答应用、套餐/配额/计量仍保留原P0范围，不因开源自动删掉。
- 53个工作包，覆盖需求表全部122个编号（含20项AC）；每项可进一步拆成PR。全是首版必需工作，未勾选不代表全部从零开发。

## 执行顺序与依赖

任务编号用于追踪，不等于简单线性顺序；每项依赖表示完成验收所需前置条件。可先开发不依赖外部服务的部分，联调仍须等待真实条件。

1. **先打通真实链路**：V1-01～03、V1-10～16、V1-21、V1-24、V1-27、V1-29；配置缺口与服务开通需求及早明确。
2. **补全知识管理与安全边界**：成员授权、元数据、切片工作台、重建清理、过滤扩展、引用与多轮。
3. **完成运营和集成**：应用策略、SDK、套餐、计量、结算和评估中心。
4. **发布验收**：故障/恢复/性能/浏览器/全链路验证，许可证、文档和制品。

V1-47～48的架构整理随对应功能PR推进，不能等功能堆完再整体重写；V1-51许可证决策与维护渠道可现在处理。整体完成比例应以验收结果计算，不按页面数量或工作包数量估算。

## 统一完成标准

每个工作包只有在以下条件满足后才能勾选：功能与错误路径实现；适用的API/UI/SDK同步；新增行为有测试；格式、静态检查、构建及适用CI通过；配置/迁移/文档一致；验收记录包含环境、数据、结果和限制。涉及真实服务的项目必须有真实证据，测试替身不代替联调。

已完成：V1-20（[验收记录](../reports/v1-20-editing.md)）、V1-19（[验收记录](../reports/v1-19-preview.md)）、V1-18（[验收记录](../reports/v1-18-quality.md)）、V1-17（[验收记录](../reports/v1-17-contexts.md)）、V1-16（[验收记录](../reports/v1-16-chunking.md)）、V1-03（[验收记录](../reports/v1-03-configurations.md)）、V1-15（[验收记录](../reports/v1-15-publication-isolation.md)）、V1-02（[验收记录](../reports/v1-02-models.md)）、V1-13（[验收记录](../reports/v1-13-ocr.md)）、V1-44（[验收记录](../reports/v1-44-fair-dispatch.md)）、V1-36（[验收记录](../reports/v1-36-entitlements.md)）、V1-48（[验收记录](../reports/v1-48-modules-contracts.md)）、V1-47（[验收记录](../reports/v1-47-java-services.md)）、V1-09（[验收记录](../reports/v1-09-lifecycle.md)）、V1-14（[验收记录](../reports/v1-14-recovery.md)）、V1-12（[验收记录](../reports/v1-12-structured-parsing.md)）、V1-11（[验收记录](../reports/v1-11-document-metadata.md)）、V1-08（[验收记录](../reports/v1-08-knowledge-base.md)）、V1-06（[验收记录](../reports/v1-06-credentials.md)）、V1-05（[验收记录](../reports/v1-05-authorization.md)）、V1-04（[验收记录](../reports/v1-04-membership.md)）、V1-01（[验收记录](../reports/v1-01-model-profiles.md)）、V1-10（[验收记录](../reports/v1-10-upload.md)）。其余任务仍按各自验收条件推进。
