# 故障排查

## 页面打不开

先运行 `docker compose ps`，确认 Web、Backend、Worker、MySQL、RabbitMQ、MinIO、etcd 和 Milvus 均在运行。检查 <http://localhost:8080/actuator/health>；数据库未就绪时不要反复重启应用，先查看数据库容器日志和磁盘空间。

## 导入任务失败

在任务中心查看阶段和安全错误码，再检查 Worker Consumer 日志。常见原因是文件超限、加密/损坏文件、OCR 超时、缺少词表缓存、队列不可达或租约过期。修复依赖后使用任务重试；不要直接修改任务状态或删除数据库记录。

## 建立索引失败

确认模型档案已发布、Embedding 维度与 Milvus collection 一致、Worker 能访问 Milvus 和模型服务。模型返回维度错误、超时、无效 JSON 或非有限分数时系统应失败；不要切换到未授权的替代模型来绕过错误。

## 检索或问答返回 503

低并发下先检查 Worker API、模型连接检测和模型服务日志。有限 CPU 的本地 Rerank 可能返回忙碌/不可用错误，这是已知容量边界；等待后重试或配置有足够容量的模型服务。不要把失败改写成空答案，也不要把无证据回答当作成功。

## 权限或数据看不到

确认登录凭证所属企业、成员状态、知识库成员关系、应用发布状态和文档版本是否已发布。服务端会把无权访问和不存在统一为 404；不要通过客户端 tenant_id/user_id 参数扩大范围。

## 恢复与删除

删除、撤权、备份和恢复都有持久化记录。需要恢复时先隔离入口，校验备份清单和密钥，再按 [恢复手册](recovery.md) 重放最新安全变更。无法确认删除或撤权状态时保持入口关闭。

## 提交安全问题

不要在公开 Issue 粘贴密钥、个人数据、业务正文或完整利用步骤。请按 [安全政策](../SECURITY.md) 私下报告。
